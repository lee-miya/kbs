# 空间测绘引擎语法速查（FOFA / Shodan / ZoomEye / Hunter / Quake）

## 1. 知识点讲解

空间测绘引擎的本质是「全网资产指纹库 + 查询语法」。价值的 80% 在组合查询：主体（域名/证书/ICP）× 指纹（组件/标题）× 条件（端口/国家/协议）。查目标时用「找全资产」，挖漏洞时用「找受影响面」。

## 2. FOFA（fofa.info）

```text
domain="example.com"                 # 根域名相关资产
host="example.com"                   # URL 含关键词（含子域）
cert="example.com"                   # 证书匹配（找隐藏资产利器）
icp="备案号"                          # 同备案主体资产
title="后台管理" && country="KR"       # 标题 + 国家
app="Apache-Shiro" && server=="/manager"
body="rememberMe" && port="8080"
icon_hash="116323821"                # favicon 哈希（找同系统站点）
(domain="example.com" || cert="example.com") && status_code="200"
```

## 3. Shodan（shodan.io）

```text
hostname:example.com
ssl:"example.com"                     # 证书字段
http.title:"登录"
http.favicon.hash:-247388890
org:"Example Corp" 200 ok
product:"Apache Tomcat" version:"9.0.30"
vuln:CVE-2021-44228                   # 需会员
```

## 4. ZoomEye / Hunter / Quake 常用等价语法

| 意图 | ZoomEye | Hunter（鹰图） | Quake |
| --- | --- | --- | --- |
| 域名资产 | `site:example.com` | `domain="example.com"` | `domain:"example.com"` |
| 证书 | `ssl:"example.com"` | `cert="example.com"` | `cert:"example.com"` |
| 标题 | `title:"后台"` | `web.title="后台"` | `title:"后台"` |
| 组件 | `app:"Shiro"` | `web.body="rememberMe"` | `app:"shiro"` |
| 图标哈希 | `iconhash:"xxx"` | `web.icon="xxx"` | `favicon:"xxx"` |
| ICP 备案 | — | `icp.name="公司名"` | `icp:"公司名"` |

## 5. 高频组合场景模板

```text
# 找某组织全部暴露面（交叉三引擎取并集）
cert="example.com" || domain="example.com" || icp="公司名"

# 找暴露的管理后台（不设关键字时按组件名）
app="泛微-EOffice" || title="泛微" || body="/general/login"

# 找某漏洞受影响面（1Day 应急测绘）
app="GitLab" && country="CN" && port="80,443"
body="/api/v4/version"

# 找测试环境/弱环境
title="测试" || body="swagger" || body="actuator" || title="phpinfo"
```

## 6. 使用技巧与坑

- 同一目标至少在两个引擎交叉验证，单引擎漏报常见（尤其政府/教育/海外资产）。
- 引擎数据有滞后（数天到数月），查到的「存活」要以实时探活为准。
- 免费额度有限：先用窄条件摸清指纹特征，再放大查询范围。
- favicon 哈希是找「同源系统站群」的最强线索，自建脚本批量算 mmh3 哈希。
