# 全流程工具与命令速查手册

> 按作战阶段组织，每条给「用途 + 最常用命令」。细节原理回链各分册。

## 阶段 0：字典与基础环境

```bash
# 必备字典

# 代理链

```

## 阶段 1：信息收集

| subfinder | `subfinder -d t.com -all -silent -o subs.txt` |

| httpx | `httpx -l alive.txt -title -td -sc -cl -o web.txt` |

## 通用纪律

- 工具上线前：本地同类环境测杀软反应 → 改特征（改名/去注释/重打包）。
- 扫描速率：生产环境白天 `--min-rate ≤1000`、nuclei `-rl ≤50`；被 WAF 封 IP 时降速+换出口。
- 每个工具的最新动态由每周情报（12）跟踪，发现「工具过时/有替代品」即更新本表（如 CME→NXC 的先例）。
