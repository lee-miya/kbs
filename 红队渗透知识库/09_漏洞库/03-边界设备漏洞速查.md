# 边界设备漏洞速查

> 用法：测绘/指纹命中产品 → 本表匹配版本与识别特征 → 最小无害验证 → 落地（回链 `03-02`）。  
> 收录标准：公网常见、预认证或低权即可造成 RCE/凭据窃取/管理面接管；按**产品族**分组。  
> 打法与决策流程见 [`../03_初始访问/02-边界设备与公开应用打点.md`](../03_初始访问/02-边界设备与公开应用打点.md)；通用 Java/OA 等仍在 [`01-高危漏洞速查（打点向）.md`](01-高危漏洞速查（打点向）.md)。  
> **周更**：新 1Day/在野洞由 `12_每周情报` **3.8 边界设备** 滚动写入本册「时效条目」；禁止完整生产级 exploit 载荷。

## 0. 打点优先级（边界专用）

| 优先级 | 目标类型 | 为什么高 |
| --- | --- | --- |
| P0 | SSL VPN / 远程接入网关 | 预认证面大、补丁滞后、一打即进内网 |
| P0 | 负载均衡 / ADC 管理口 | 流量枢纽；管理面常误暴露公网 |
| P1 | 防火墙 / UTM 管理口、WAF 管理口 | 权限极高；常与 VPN 同机 |
| P1 | 邮件安全网关 / 安全邮件 | 可读全员邮件或转发 |
| P2 | 堡垒机 / PAM | 可跳板全域运维会话 |
| P2 | 零信任 / SDP 控制台 | 身份与策略中枢 |

纪律：先证「管理/VPN 口是否公网」再谈洞；很多「洞」本质是**暴露面错误**。

## 1. Fortinet（FortiGate / FortiOS / FortiProxy 等）

| 漏洞 | 影响版本（以官方为准） | 识别特征 | 利用要点 |
| --- | --- | --- | --- |
| CVE-2024-21762 | FortiOS SSL-VPN 受影响构建 | `/remote/login` 等 SSLVPN 口；版本头/SSL 证书 OU | **预认证**堆溢出 RCE；已大规模在野；优先升补丁并查历史会话/新账户 |
| CVE-2023-27997 (heap overflow) | 多版本 FortiOS/Proxy | 同上 | 预认证 RCE；与 21762 同属「VPN 口必扫」 |
| CVE-2022-42475 | FortiOS SSL-VPN | 同上 | 预认证 RCE；存量未修仍可见 |
| CVE-2018-13379 等路径穿越 | 老构建 | `/remote/fgt_lang?lang=/../../../` 类路径 | 任意文件读 → 会话/哈希；常作 Nday 链第一步 |
| FortiSandbox 系列（KEV 滚动） | 以 CISA/厂商为准 | 沙箱管理 Web | 管理面认证绕过/RCE 入 KEV 时升格本表 |

指纹：标题含 FortiGate/FortiOS；常见端口 443/10443；证书常见 Fortinet。

## 8. 国产 VPN / 安全网关 / 堡垒机（打点高频）

> 版本与编号随厂商通告滚动；下列为**方向级**速查，具体 CVE 以当周周报写入时效条目为准。

| 产品族 | 历史高危方向 | 识别 / 指纹线索 | 利用与落地要点 |
| --- | --- | --- | --- |
| 深信服 SSL VPN / 应用交付 | 任意文件读、命令注入、会话伪造 | 标题/路径含 `por`、`login_psw`、sangfor；默认口令思路 `sangfor/sangfor` | 先版本指纹再选 Nday；读配置拿账密；shell 后优先本机路由/隧道配置 |
| 奇安信 / 网康 NS-ASG 等 | 文件下载、命令执行、未授权 | `NS-ASG`、网康标题；特定 download 脚本路径 | 文件读→凭据；管理口与门户分离看暴露 |
| 天融信 / 华为 / 新华三 / 启明星辰 等 VPN·防火墙 | 命令注入、越权、默认口令 | 各厂登录页特征、证书 CN | 管理口公网=高危；优先默认口令与已知 Nday |
| 齐治堡垒机 | 未授权/弱口令/历史 RCE | 齐治登录页 | 拿堡垒≈拿一批主机会话 |
| JumpServer | 未授权访问、历史 RCE、API 密钥 | `/core/auth/login/`；JumpServer 标题 | 升级到厂商修复版；API Token 泄露等同接管 |
| 邮件网关（Coremail 等） | 配置泄露、上传、管理绕过 | 邮件登录页指纹 | 读配置/会话后钓鱼面扩大（回链 03-01） |

## 9. 负载均衡 / WAF / 邮件安全（边界邻接）

| 类型 | 代表 | 要点 |
| --- | --- | --- |
| 负载均衡 | F5、LoadMaster、Nginx Plus 管理口、国产 ADC | **管理面 RCE/命令注入**优先于数据面；已入 KEV 的 LoadMaster 见 §7 |
| WAF 管理口 | 各类云 WAF / 硬件 WAF | 默认口令、管理 API 未鉴权；打穿后可下发放行规则掩护后续流量 |
| 邮件安全 | Proofpoint/Mimecast 类网关少见自研洞；国产网关 Nday 多 | 以厂商公告为准；常作钓鱼投递旁路情报源 |

## 10. 默认口令与暴露面（边界专项）

| 产品线索 | 常见默认 / 弱口令思路 |
| --- | --- | --- |
| 深信服系 | `admin`/`admin`、`sangfor`/`sangfor`、出厂改密未改 |
| 防火墙/VPN 管理 | `admin`/`admin123`、`admin`/`password`、设备序列号变体 |
| 堡垒机 | 出厂 admin；文档默认口令未改 |
| 监控邻接 | Zabbix `Admin/zabbix`；Grafana `admin/admin`（常与边界同段） |

暴露面检查清单：

1. SSLVPN 门户是否与**管理 UI**同口或可跳转管理。  
2. 是否仅 IP 白名单/零信任前置（无则降风险评级上调）。  
3. 证书、标题、favicon、特殊路径是否与内网同产品集群一致（找「影子设备」）。

## 11. 验证纪律（边界必须更克制）

1. **先无害**：版本横幅、公开路径 404/200 差异、厂商安全头；DNSLog/空连接即可证可达。  
2. **再有限**：只在授权范围内用公开 PoC 的**检测逻辑**（非破坏性）；禁止一上来写马。  
3. **证据六要素**：产品、版本/构建、URL、漏洞编号、验证截图、业务影响（能否进内网/读凭据）。  
4. **打穿后第一件事**：本机路由表、隧道用户列表、配置中的域/LDAP、下一跳防火墙策略——再谈横向（`05`）。  
5. 需要代码/配置根因时回链审计库；本册只服务**打点匹配**。

## 使用纪律

1. 版本以**厂商安全公告**为准；表中「受影响版本」仅作检索入口。  
2. 单一自媒体称「在野」而无 KEV/厂商/大厂 IR 交叉 → 标「待核实」，只进时效区。  
3. 旧洞确认近无公网存量时可移入文末「档案」并在周报记录。  
4. 与 `01` 表重复的条目：以**本册为边界权威**；`01` 仅保留一行回链，避免双源漂移。

## 自测锚点

- [ ] 给定 SSLVPN/网关指纹，5 分钟内在本表定位候选洞并说出「预认证还是要账密」。  
- [ ] 能口述边界打点优先级：VPN → ADC 管理口 → 防火墙管理口 → 堡垒机。  
- [ ] 能说明为何「管理面误暴露」经常比「新 CVE」更致命。  
- [ ] 打穿后能列出至少 4 项本机情报（路由/用户/LDAP/隧道配置）再进入内网阶段。
