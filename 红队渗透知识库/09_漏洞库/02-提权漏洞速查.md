# 提权漏洞速查

> 用法：`uname -a` / `systeminfo` → 本表匹配版本 → 查 PoC 成熟度 → 备份通道后执行。
> 纪律：内核 exp 有打崩风险，生产环境必须选「稳定 PoC」列标的；先开备用 shell/持久化再跑。

## Linux 内核 LPE（按年份倒序，常用）

| 漏洞 | CVE | 影响范围（要点） | 稳定性/备注 |
| --- | --- | --- | --- |
| Copy Fail | CVE-2026-31431 | 主流发行版特定内核段 | 页缓存篡改 su/sudo 注入 shellcode；有 Python/C/Go/Rust 多语言 PoC，稳定性好，EDR 对抗要点：文件完整性告警 |
| Dirty Frag | —（2026 披露） | 见每周情报更新 | 页缓存/碎片利用系，参考 12 分册最新分析 |
| DirtyCred | CVE-2022-2588 | 内核 ≤5.18 | 凭据对象替换，通用性强 |
| PwnKit | CVE-2021-4034 | polkit pkexec 全发行版（装 polkit 即有） | 极稳定，首选之一；argv 环境变量越界写 |
| DirtyPipe | CVE-2022-0847 | 5.8~5.16.11 | 写只读文件改 /etc/passwd/SUID；极稳定，容器同杀 |
| OverlayFS | CVE-2021-3493 / CVE-2023-0386 | Ubuntu 系 | fuse-overlayfs 组合 |
| nftables 系列 | CVE-2022-32250 / 2023-0179 / 2024-1086 | 启用 nf_tables | Ubuntu 系命中率高 |
| Sequoia | CVE-2021-33909 | 2014 以来全版本 | 文件系统深路径越界，稳定但内存需求大 |

选洞流程：`uname -r` + 发行版 → 上表行 → GitHub 搜「CVE 编号 + exploit」→ 看 star/最近提交/评论确认可用性 → 本地同版本编译测试再上目标。

补丁核查：`systeminfo` → wesng 离线比对缺失补丁 → 反查可用的公开 exp。

## EDR 环境下的提权注意

- 文件落盘 exp 必死：改用内存加载（reflective/BOF 版 Potato、SweetPotato）。
- 内核 exp 触发补丁防护（PatchGuard）风险：优先配置错误类提权（sudo/SUID/服务权限），漏洞类作最后选项。
- Linux 上 EDR 对「改 su/sudo 文件」「异常 SUID 创建」告警敏感：Copy Fail 类利用后尽快恢复或转配置型持久化。

## 经验沉淀

- 提权成功率排序：配置错误 > 内核 Nday（有稳定 PoC）> 服务漏洞 > 0day。
- 永远先问「这台机器跑的业务以谁的身份跑」——服务账户特权往往是设计好的提权电梯。
- 每打成功一个洞，把「版本指纹 → 选洞理由 → exp 链接 → 实测结果」沉淀回本表（或每周情报）。
