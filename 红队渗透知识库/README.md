# 红队渗透知识库 · 总索引

> 定位：覆盖红队渗透全流程的可自学知识库。分册体例：「原理 → 工具与命令 → 场景 → 自测锚点」（详见 [`../维护/文档体例约定.md`](../维护/文档体例约定.md)）。  
> 使用原则：仅在获得明确书面授权的目标与范围内使用；仅用于防御研究与授权测试。  
> 需要挖源码根因时，转到 [`../代码审计知识库/`](../代码审计知识库/README.md)。

## 一、目录地图

| 分区 | 内容 | 解决的问题 |
| --- | --- | --- |
| `00_方法论与作战流程` | PTES / 杀伤链 / ATT&CK / 行动准则 | 行动没有章法、报告缺骨架 |

| `11_自学体系` | 能力自测清单、学习路线与靶场 | 不知道自己缺什么 |
| `12_每周情报` | 每周更新的渗透情报（原料） | 跟踪最新手段；两周内回链分册 |

## 三、自学路线（三级进阶）

- **L1 筑基**：网络与系统基础 → Web 漏洞原理（02 分册）→ 单机提权（04 分册）。自测：能独立打穿 DVWA/upload-labs 全部关卡，能讲清每类漏洞成因。
- **L2 内网**：信息收集自动化（01 分册）→ 凭据与横向（05-02 / 05-03）→ 域渗透（05-01）。自测：能在 GOAD/vulntarget 靶场独立拿下域控。
- **L3 对抗**：C2（06-01）与免杀（06-02）→ 持久化与反溯源（07）→ 云与容器（08）→ 漏洞库自主逆向补漏（09）。自测：能在有 EDR 的靶场完成从打点到数据获取的全链路并写复盘。

配套清单：`11_自学体系/01-能力自测清单.md`（逐项打勾）、`11_自学体系/02-学习路线与靶场资源.md`。

## 四、查缺补漏用法

1. 打开 `11_自学体系/01-能力自测清单.md`，按领域自评打分，标出「不能独立做到」的条目。
2. 按清单最后一列的链接跳到对应分册精读，并完成文末「自测锚点」。
3. 实战中遇到库中没有的情况，先记入 `12_每周情报` 当周的「待沉淀」区，周末整理成新条目并入对应分册。

## 五、每周情报更新

每周一产出归档到 `12_每周情报/`（模板见该目录 README）。须按 [`../维护/周更重点关注源.md`](../维护/周更重点关注源.md) **大范围**扫专家博客/厂商/论坛，并优先精析 AI 代码审计案例；**免杀/EDR** 有长期价值的手法回链 `06-02` 时效；**钓鱼/初始访问** 回链 `03-01` 时效。重要打点条目回链 `09_漏洞库` 等分册。
全库周更与缺口路线图：[`../维护/每周更新SOP.md`](../维护/每周更新SOP.md)、[`../维护/内容缺口与补充路线图.md`](../维护/内容缺口与补充路线图.md)。
代码层模式同期**直接**写入 [`../代码审计知识库/`](../代码审计知识库/README.md) 对应分册「时效条目」。
