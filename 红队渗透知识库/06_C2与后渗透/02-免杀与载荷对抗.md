# 免杀与载荷对抗

> 定位：主机侧「上线不被杀、作业不响铃」的可复习分册；与 [`01-C2框架与EDR对抗.md`](01-C2框架与EDR对抗.md) 分工——01 管框架选型与流量基建，**本册管检测点矩阵、loader 管线、本地验证纪律与周更时效**。  
> 红线：仅公开原理与授权实验室验证思路；**禁止**入库可直接打穿生产的完整免杀载荷/一键脚本。  
> 更新：2026-08-12（v1.0：首建 + 接入周更）

## 1. 原理：免杀在对抗什么

免杀 ≠ 「改个 hash 永不过杀」。EDR/杀软大致覆盖四层，对策必须对层下药：

| 层 | 典型机制 | 红队目标 |
| --- | --- | --- |
| 静态 | 签名、YARA、熵/导入表启发式 | 落盘样本不可识别或根本不落盘 |
| 脚本/托管 | AMSI（PowerShell/.NET/VBA）、脚本录制 | 绕过或避开脚本宿主 |
| 内存 | 周期性扫描、解密后特征、堆栈回溯 | sleep 期加密自身、减少明文驻留 |
| 行为/遥测 | ETW、用户态 hook、内核回调、ML 行为链 | 降噪父进程/命令行/敏感 API 组合 |

一句话：**先判断「死因」（静态 / AMSI / 内存 / 行为 / 流量），再换对应层的手法；盲目换壳是最低效路径。**

## 2. 检测点 → 对策矩阵（可执行检查单）

| 检测点 | 常见告警线索 | 对策方向（原理级） | 本地自测 |
| --- | --- | --- | --- |
| 文件静态 | Defender 实时拦截、哈希命中 | 无文件加载；加密分离；改导入表/段名；少用公开免杀马原样 | 同版本 Defender 离线机投递 |
| AMSI | `AmsiScanBuffer` 命中脚本/程序集 | 避开 PS 宿主；.NET 反射；内存补丁思路（实验室） | 开 AMSI 日志看是否仍扫描 |
| ETW | 安全产品订阅 Provider 后行为串联 | 减少高噪声 Provider 暴露；作业改 BOF/合法工具 | 对比补丁前后事件量（靶场） |
| 用户态 API hook | EDR DLL 注入后 `VirtualAlloc`/`CreateRemoteThread` 告警 | 直接/间接 syscall；回调执行代替显式 CreateThread | API Monitor / 厂商演示环境 |
| 内存扫描 | beacon 明文在 RWX 页被扫中 | sleep obfuscation；执行后改保护属性；短生命周期 staging | 睡眠前后 dump 对比 |
| 行为链 | `winword → powershell → rundll32` 等亲缘链 | PPID spoof；少 spawn；用已签名进程模块路径 | Sysmon 看 Parent/CommandLine |
| 流量侧 | JA3/URI/UA 指纹、非标 SNI | 见 01 分册 malleable + 重定向器 | 抓包对照 profile |

## 3. Loader 管线（理解阶段，不背特定 PoC）

```text
① 载荷制备：C2 agent / 工具 → shellcode（donut/sRDI 等）或加密 blob
② 载体选择：C / C# / Go / Rust / Nim / 合法签名进程旁加载
③ 分配与权限：避免「一分配就 RWX」固定模式；按阶段改 PAGE_* 
④ 解密与执行：密钥分离（资源/远程/参数）；线程 / 纤维 / 回调 / 早期鸟等执行原语择一
⑤ 可选降噪：AMSI/ETW 相关处理（仅授权靶场）；进入 sleep 混淆
⑥ 作业面：优先 BOF / 原生命令；少起 cmd.exe / powershell.exe
```

### 决策表：什么环境用什么底线

| 环境信号 | 最低动作 | 不建议 |
| --- | --- | --- |
| 仅 Defender 家用/入门 | 无文件 + 基础混淆 + 本地实测 | 直接丢公开 GitHub 免杀马 |
| 企业 EDR（有行为链） | 上表行为层 + sleep + 少 spawn | 上线后立刻 mimikatz 三连 |
| 强沙箱/引爆机 | 延时、环境键（用户/域名/分辨率）抗沙箱 | 一运行就连 C2 |
| 已有稳定会话 | 换通道/换 loader，不叠加重载荷 | 同特征反复重传 |

## 5. 使用场景与作战纪律

1. **钓鱼/附件前**：在与目标同大版本的干净 VM 实测；记录拦截层（静态/AMSI/行为）。
2. **Web 落地后**：有 EDR 优先内存马/无文件通道（见 `03-04`），再迁 C2；文件马仅作短跳板。
3. **提权/横向**：工具本身也要过免杀关；优先 Living-off-the-Land，减少自带 exe。
4. **翻车复盘**：死因 → 改哪一层 → 写入本分册「时效条目」+ 当周周报工具/方法论区。

### 2026-08-12 · 过静杀 ≠ 过对抗：内核驻留叠加（Check Point / Lazarus）

- **检测层**：行为 + 内核（驱动加载 / 提权后 rootkit）
- **手法**：钓鱼初始访问后，利用在野 LPE（CVE-2026-68820 AFD.sys）部署内核级组件；红队侧启示是噪音预算须覆盖「提权 + 驱动」，不能只优化用户态 loader
- **适用条件**：已获本地码执行；补丁滞后环境
- **本地自测**：授权机确认 08-11 PT 是否覆盖 AFD；Sysmon/驱动列表基线对比（防御验证同样适用）
- **局限**：不讨论 FudModule 实现细节与完整利用链
- **链接**：https://research.checkpoint.com/2026/shattering-the-dream-when-a-job-offer-becomes-a-zero-day-attack/

### 2026-08-12 · 主机致盲窗口 ↔ 网络侧补位（EDR-Freeze 类公开讨论）

- **检测层**：行为（进程挂起/扫描盲窗）+ **流量**
- **手法**：公开讨论的一类思路是短时挂起安全产品相关进程，制造用户态扫描盲窗；红队自测启示是「主机静默 ≠ 作业不可见」——C2/出站仍可能被网络侧抓住
- **适用条件**：本地已有足够权限；目标 EDR 进程保护弱；有旁路流量检测时主机致盲收益下降
- **本地自测**：授权 VM：故意制造安全进程异常暂停时段，对照是否仍有 DNS/TLS/JA3/代理日志告警；判死因时把「流量层」列入清单
- **局限**：不入库挂起实现与生产级致盲工具；MDSec/Outflank 近 7 日无新深文达标，本条为对抗框架补位
- **链接**：公开检索线索（EDR-Freeze / ExtraHop EDR evasion anatomy）；下期继续扫 MDSec 标签页

### 2026-08-15 · AMSI 走 RPC 委托：挂钩 NdrClientCall 而非补丁 amsi.dll（Elastic）

- **检测层**：AMSI + 行为（Script Block / API 遥测）
- **手法**：AMSI 把扫描请求经 RPC 交给杀软；挂钩 `rpcrt4!NdrClientCall3`（或 `NdrClientCall2`）可在到达引擎前篡改结果，`amsi.dll` / `AmsiScanBuffer` 可保持原样
- **适用条件**：脚本托管路径（PowerShell 等）；纯内存或编译实现可躲开 4104
- **本地自测**：授权 VM 开 Script Block Logging，检索是否同时出现 `NdrClientCall*` 与 `VirtualProtect`/`GetProcAddress`/`GetDelegateForFunctionPointer`；有 EDR API 遥测时盯对 `rpcrt4` 的保护修改
- **局限**：不入库挂钩实现与生产 loader；MDSec 近周仍无深文
- **链接**：https://www.elastic.co/guide/en/security/8.19/potential-amsi-bypass-via-rpc-runtime-hooking.html

### 2026-08-29 · 会议客户端目录 DLL 旁加载（Head Mare / TrueConf）

- **检测层**：静态（网关只见「官方会议客户端」）+ 行为（会议进程加载非原厂 DLL / 异常 CLSID）
- **手法**：合法会议安装目录旁放伪装系统 DLL，并用 HKCU CLSID `InprocServer32` 持久化；常接在会议服失陷后的更新/下载链
- **适用条件**：用户会跑会议安装包或自动更新；应用目录可写
- **本地自测**：授权 VM：对照主程序签名 vs 同目录 DLL；Sysmon ImageLoad + 启动项/CLSID 基线
- **局限**：不入库具体 DLL 名利用包与完整样本；MDSec/Outflank/Elastic 本窗口无新深文
- **链接**：当周周报 3.6；CISA TrueConf KEV 08-20

### 2026-09-19 · RpcGhosting 选择性挂钩：只拦 AMSI 来源的 NdrClientCall（Practical Security Analytics）

- **检测层**：AMSI + 行为（进程内 RPC）+ **TLS/COM 副作用**
- **手法**：无条件补丁 `NdrClientCall3` 返回 `RPC_S_SERVER_UNAVAILABLE` 会让 AMSI fail-open，但也打断同进程证书校验/COM；改进形态是 trampoline **检查调用者是否 amsi.dll**，仅对 AMSI 返回错误，其余放行。08-15 条仍有效；本条补「选择性挂钩」演进。
- **适用条件**：脚本或 loader 能改 `rpcrt4`；企业 EDR 若只盯 `AmsiScanBuffer` 会漏。
- **本地自测**：授权 VM：对照无条件挂钩是否搞挂 HTTPS 下载；有 API 遥测时盯对 `rpcrt4!NdrClientCall*` 的保护修改，且调用栈来自 amsi。
- **局限**：不入库挂钩实现与生产 loader；Elastic 8.19 规则仍主要吃 4104 脚本块。
- **链接**：https://practicalsecurityanalytics.com/improved-rpcghosting/ · Elastic `defense_evasion_amsi_bypass_rpc_ndrclientcall`

### 2026-08-15 · 签名 PDF 阅读器 + 同目录 DLL 劫持（CPR / Lazarus）

- **检测层**：静态（网关只见签名 EXE）+ 行为（阅读器加载非原厂 DLL）
- **手法**：投递合法签名 PDF 阅读器，同目录放 `libmupdf.dll` 劫持；或改 SecurityPDF，打开带标记的「PDF」时解密执行。邮件/网关常放行「阅读器」
- **适用条件**：用户会解压并运行阅读器；应用目录可写
- **本地自测**：授权 VM：对照主程序签名 vs 同目录 DLL 签名/路径；Sysmon ImageLoad 看 PDF 进程是否加载非厂商 DLL
- **局限**：不入库完整阅读器改写与 payload；SpecterOps/看雪免杀近 7 日仍无达标深文
- **链接**：https://research.checkpoint.com/2026/shattering-the-dream-when-a-job-offer-becomes-a-zero-day-attack/
