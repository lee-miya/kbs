# 边界设备与公开应用打点

## 1. 知识点讲解

打点的本质是「用最小的代价换第一个代码执行点」。优先级排序：已知 Nday 未修 > 组件默认口令/未授权 > 通用漏洞（注入/上传）> 钓鱼绕行。边界设备（VPN、防火墙、邮件网关、堡垒机）权重最高：权限高、网络位置好、补丁滞后。

## 2. 打点决策流程

```text
资产指纹（httpx/测绘）
  → 命中漏洞库？(09-01 查表) → 有 → 验证 → 利用 → 落地 shell
  → 无 → 默认口令/未授权？(组件手册+指纹库)
  → 无 → 通用漏洞测试（02 分册）
  → 无 → 换资产（软柿子优先，别死磕主站）
```

## 3. 高价值边界目标清单

| 类型 | 常见产品 | 历史高危方向 |
| --- | --- | --- |
| VPN/SSLVPN | 深信服 SSLVPN、奇安信网康、Pulse、FortiGate、Sangfor | 任意文件读取、预认证 RCE、凭据泄露目录 |
| 邮件系统 | Exchange、Coremail、亿邮 | ProxyShell/ProxyLogon、Coremail 配置泄露 |
| OA/协同 | 泛微 E-Office/Ecology、致远 A8、蓝凌 | 文件上传、SQL 注入、反序列化 |
| 网盘/文档 | 联想网盘、亿方云 | 未授权、上传 |
| 堡垒机/运维 | 齐治、JumpServer | 未授权 RCE、默认口令 |
| 监控/运维 | Zabbix、Grafana、Nagios | 默认口令、SQLi、模板 RCE |
| DevOps | GitLab、Jenkins、Nexus、Harbor | 未授权、反序列化、脚本控制台 |
| 边界安全设备 | 防火墙/WAF 管理口 | 命令注入、越权 |

（各组件具体漏洞编号与利用要点统一维护在 `09_漏洞库/01-高危漏洞速查（打点向）.md`，本文只讲打法。Exchange 的深度打法见 `03-Exchange专项.md`，落地形态选型见 `04-内存马专项.md`。）

## 4. 验证到落地的标准动作

1. **指纹识别**：标题、favicon hash、特殊路径（`/login.action`）、Server 头，与测绘语法互查（01-02）。
2. **最小验证**：DNSLog 回显、`id`/`whoami` 写入静态目录回读——证明存在即可截图存证。
3. **shell 落地三选**：
   - 文件马：找可写可解析目录；jsp/php 免杀马；
   - 内存马（Java 中间件首选）：Filter/Servlet/Listener 型注入 Tomcat，无文件落地——选型、注入通道与反排查详见 `04-内存马专项.md`；
   - 命令回显通道：不出网时改响应头/写文件读。
4. **出站判断**：`ping/curl DNSLog`、`powershell IEX` 测试出站协议白名单，决定反弹、HTTP 隧道还是代理落地（05-03）。

## 5. 默认口令与未授权速查思路

- 按指纹查「产品名 + 默认口令」（admin/admin、admin/123456、sangfor/sangfor）。
- 未授权接口：API 文档泄露（swagger）、 actuator 端点、`/druid` 监控页、Hadoop YARN、Docker Remote API(2375)、Kubernetes kubelet(10250)。
- 控制台暴露：Jenkins script console、Tomcat manager、Weblogic console（结合部署 war 拿 shell）。

## 6. 打点后的第一件事（衔接内网）

```bash
# 就地情报三件套
ipconfig /all & netstat -ano & tasklist        # Windows
ip a; ss -antp; ps aux                         # Linux
# 读配置拿密码：数据库连接串、历史命令、浏览器保存密码 → 为横向（05）囤弹药
```

原则：打点机器本身是情报富矿，别急着扫内网，先翻本机。
