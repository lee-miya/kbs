# 每周情报 · 使用说明

## 机制

计划任务每周一 09:00 自动执行：按 [`../../维护/周更重点关注源.md`](../../维护/周更重点关注源.md) **大范围**检索过去一周的渗透手段、专家博客、厂商实验室、**AI 代码审计案例**、**CTF 奇技淫巧**、**免杀/EDR 对抗**、**钓鱼/初始访问**、**边界设备**与 **同类 AI 攻防 skill 仓库**，产出一份情报文件存放于本目录，命名格式：`YYYY-MM-DD_每周渗透情报.md`。

## 维护纪律

1. 每期情报产出后，**两周内**把有长期价值的条目回链并入对应分册（01~10），否则情报只是流水账。
2. 「个人沉淀区」是手工区：本周实战/靶场收获写这里；**含真实域名/IP/客户名/路径时，先写到仓库根目录 `个人笔记/`（已 gitignore），脱敏后再摘抄进本区或升格分册**。
3. 超过 12 期的旧情报整包归档（`archive/` 子目录），保持目录清爽。
4. 推送前按 [`../../维护/隐私与脱敏排查清单.md`](../../维护/隐私与脱敏排查清单.md) 自检。
5. 检索范围与源清单以 [`../../维护/每周更新SOP.md`](../../维护/每周更新SOP.md) 为准；缺扫 P0/P1、空过 AI 案例节、CTF 奇技节、**免杀 3.6**、**钓鱼 3.7**、**边界 3.8**或**同类 skill 3.9**视为未达标。
