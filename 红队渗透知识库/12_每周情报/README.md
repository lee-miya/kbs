# 每周情报 · 使用说明

## 机制

计划任务每周一 09:00 自动执行：检索过去一周的最新渗透手段、思路与方法论，产出一份情报文件存放于本目录，命名格式：`YYYY-MM-DD_每周渗透情报.md`。

## 每期文件结构（模板）

```markdown
# YYYY-MM-DD 每周渗透情报

## 1. 新漏洞与新利用（重点：可武器化的）
| 漏洞/组件 | 类型 | 影响 | 利用成熟度 | 链接 | 建议动作 |
（建议动作：写入 09 漏洞库 / 观察 / 忽略）

## 2. 工具动态（新工具、重大更新、替代品）
| 工具 | 变化 | 是否更新 10 工具速查 |

## 3. 方法论与思路精选（博客/演讲/报告）
- 标题 — 一句话精华 — 链接 — 对应分册回链

## 4. AI 攻防动态（AI 辅助渗透与对抗的新进展）

## 5. 个人沉淀区（手工填写）
- 本周实战中值得固化的经验 / 待补的缺口

## 6. 入库动作记录
- [ ] 已把 X 条目并入 09_漏洞库
- [ ] 已把 Y 命令更新进 10_工具速查
```

## 维护纪律

1. 每期情报产出后，**两周内**把有长期价值的条目回链并入对应分册（01~10），否则情报只是流水账。
2. 「个人沉淀区」是手工区：你本周实战/靶场的收获写这里，沉淀够了就升格为正式分册条目。
3. 超过 12 期的旧情报整包归档（`archive/` 子目录），保持目录清爽。
