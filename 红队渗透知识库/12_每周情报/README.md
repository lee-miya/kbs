# 每周情报 · 使用说明

## 机制

计划任务每周一 09:00 自动执行：按 [`../../维护/周更重点关注源.md`](../../维护/周更重点关注源.md) **大范围**检索过去一周的渗透手段、专家博客、厂商实验室与 **AI 代码审计案例**，产出一份情报文件存放于本目录，命名格式：`YYYY-MM-DD_每周渗透情报.md`。

## 每期文件结构（模板）

```markdown
# YYYY-MM-DD 每周渗透情报

> 覆盖窗口：…  
> 本周已扫源：P0 官方/厂商 □ · P0 AI 审计专扫 □ · P1 国际精读 n · P1 国内精读 n

## 1. 新漏洞与新利用（重点：可武器化的）
| 漏洞/组件 | 类型 | 影响 | 利用成熟度 | 链接 | 建议动作 |
（建议动作：写入 09 漏洞库 / 观察 / 忽略）

## 2. 工具动态（新工具、重大更新、替代品）
| 工具 | 变化 | 是否更新 10 工具速查 |

## 3. 方法论与思路精选（专家博客 / 实验室 / 论坛回原文）
- 标题 — 一句话精华 — 作者/来源 — 链接 — 对应分册回链
（至少 2 条来自关注源 P1，避免只摘聚合站）

## 4. AI 攻防与 AI 审计案例
### 4.1 攻防态势（利用自动化、Agent 攻击面等）
### 4.2 代码审计案例精析（本周重点）
- 按体例：场景 / 管线分工 / 提示词结构 / 工具接入 / 验证闭环 / 局限 / 可迁移纪律
- 详情写入审计库综合分册「五、AI 审计案例提炼」；此处保留摘要 + 链接
- 若无达标案例：写「无达标案例」+ 已搜关键词与已扫源

## 5. 个人沉淀区（手工填写）
- 本周实战中值得固化的经验 / 待补的缺口
- 本周试用 AI 审计时的有效提示词或翻车记录（脱敏后）

## 6. 入库动作记录
- [ ] 已把 X 条目并入 09_漏洞库
- [ ] 已把 Y 命令更新进 10_工具速查
- [ ] 已把 AI 案例精析写入综合分册第五节（或注明无）
- [ ] 可迁移纪律已回链通用方法论（如有）
```

## 维护纪律

1. 每期情报产出后，**两周内**把有长期价值的条目回链并入对应分册（01~10），否则情报只是流水账。
2. 「个人沉淀区」是手工区：本周实战/靶场收获写这里；**含真实域名/IP/客户名/路径时，先写到仓库根目录 `个人笔记/`（已 gitignore），脱敏后再摘抄进本区或升格分册**。
3. 超过 12 期的旧情报整包归档（`archive/` 子目录），保持目录清爽。
4. 推送前按 [`../../维护/隐私与脱敏排查清单.md`](../../维护/隐私与脱敏排查清单.md) 自检。
5. 检索范围与源清单以 [`../../维护/每周更新SOP.md`](../../维护/每周更新SOP.md) 为准；缺扫 P0/P1 或空过 AI 案例节视为未达标。
