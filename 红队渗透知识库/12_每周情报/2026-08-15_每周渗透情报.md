## 3. 方法论与思路精选（专家博客 / 实验室 / 论坛回原文）

- **厂商降级描述 ≠ 可达上限**（watchTowr · NetScaler）：公告写 Memory Overflow / DoS，补丁却在 SAML `ds:SignedInfo` 拷贝处加长度检查；未认证可达的固定缓冲拷贝应按内存破坏评估，而不是停在「可用性」。回链：09-03、03-02。
- **专长编码 + 确定性门禁 + cascade**（PortSwigger · HTTP Terminator 全文）：Ideation → 授权目标 Evaluation → Weaponization → 对每个成立假说追邻近分支。验证成功与否交给**不可被模型改写的代码**，LLM 只负责假说与证据。回链：综合分册五、方法论十一。
- **路径安全检查必须正交**（看雪 · 2026 软安赛 Web）：`contains("..") && cleanPath().contains("../")` 两段不是同一语义；`///` 产生空路径段可让规范化结果不再含 `../`。回链：Java 时效、综合 CTF 拾遗。
- **AMSI 未改 ≠ AMSI 仍有效**（Elastic）：扫描请求走 RPC 委托；挂钩 `NdrClientCall3/2` 可在到达引擎前篡改结果，`amsi.dll` 完好。回链：06-02。
- **边界打点不要只扫门户**（PAN GP 08-12）：预认证网关没洞时，**客户端 VPN 栈**（CBL/SAML/UDP 隧道）仍是初始访问面；需路径 MitM 或伪网关。回链：03-01、03-02、09-03。
- **未修自托管 BI = 失陷假设**（Metabase 跟进）：KEV 之后公开多起自托管实例失陷；动作从「排队打补丁」升为「当已失陷：轮换连接库凭据 + 查管理员」。回链：09-01。
