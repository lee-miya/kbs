## 3. 方法论与思路精选（专家博客 / 实验室 / 论坛回原文）

- **Autofix 会拆掉当年防注入的 `env:` + `jq --arg`**（Wiz · Snowflake）：「看起来更干净」的 shell 展开把议题标题送进 `echo '...'`；`sed` 转义发生在 GitHub 模板展开**之后**，单引号即可破。AI 安全评审同 PR 未拦。回链：方法论十一、Python 时效。
- **失败路径要喂给 Agent**（Wiz Red Agent）：第一次用 `#` 注释吃掉 `$(...)` 的闭括号导致 bash 意外 EOF；Agent 读错误后改 `; echo '` 闭合。验证闭环含「执行失败也是信号」。回链：综合分册五。
- **UA 前缀黑名单不是浏览器隔离**（Ray GHSA）：`fetch` 规范允许改 `User-Agent`；Firefox/Safari 可改，Chrome 因实现偏差反而安全。本地 Dashboard 无认证 + DNS rebinding = 开发机 RCE。回链：09-01、03-01。
- **Python 3.12+ 字节码 CACHE 槽全 0**（看雪 · KCTF 第二题）：循环 XOR 下密文对应位置直接泄露 key；逻辑可藏在重编 `python313.dll` 的 frozen `os`，entry 脚本是空壳。回链：综合拾遗、Python 时效。
- **显式代理也是 FortiOS 攻击面**（FG-IR-26-161）：不要只扫 `/remote/login`；Kerberos + SOCKS 的 WAD 路径是另一条预认证内存面（条件苛刻）。回链：09-03、03-02。
- **图上的可达只是候选**（offensive-claude v1.9）：source-to-sink 边带 EXTRACTED/INFERRED/AMBIGUOUS；非全 EXTRACTED 的 CONFIRMED 必须降级。与 KBS「默认 C 级」同构。回链：方法论十一。
