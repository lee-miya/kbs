## 3. 方法论与思路精选

- **安全边界 fail-open**：EncryptInterceptor「解密失败仍继续 dispatch」——凡「先校验/解密再处理」的实现，必须确认失败路径有 `return`/`drop`，不能只打日志。回链：审计 Java 分册、通用方法论。
- **校验正交性**：CodeIgniter `is_image`/`mime_in` 只看内容魔数、不看扩展名——内容校验与扩展名/存储名必须独立且同时满足。回链：PHP 上传节、Web 渗透上传。
- **AI Agent 攻击面**：Langflow 类「低代码 + 代码执行端点」默认组合 = 未授权 RCE；云上 SRE Agent 的 OBO 越权说明「代理身份」扩大爆炸半径。回链：综合分册、云与容器。
- **补丁回归**：Tomcat 修复 padding oracle 时引入新洞——N-day 审计要对「安全补丁本身」做 diff，不只看功能 commit。
