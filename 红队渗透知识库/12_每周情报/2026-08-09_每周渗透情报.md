## 3. 方法论与思路精选（专家博客 / 实验室 / 论坛回原文）

- **安全边界 fail-open**（Corgea / Tomcat 分析）：解密失败仍 dispatch——失败路径必须中止。回链：Java 分册、通用方法论。
- **校验正交性**（CI4）：内容魔数 ≠ 扩展名/存储名，须同时满足。回链：PHP、Web 上传。
- **MSP/RMM = 全域跳板**（THN / N-able）：管理面认证绕过后经远程控制通道打终端——打点优先级等同域控周边。回链：09、内网分册（后续加厚）。
- **CI/CD 反序列化入口**（Rapid7 · TeamCity）：未认证 HTTP 反序列化 → 构建凭据与供应链。审计时优先枚举「接受序列化对象的管理 API」。
- **长周期恶意 PR**（PRWeaver）：单看一个 PR 不够；良性载体融合与整窗审阅会显著掉检测率——AI 审 PR 要跨 PR 串联不变量。回链：综合分册五、方法论十一。
- **图收敛再喂模型**（CodePecker / SegmentFault 08-06）：先确定性代码图缩小子图，仅脱敏路径进 LLM，再确定性验证——降 Token、防全量外传、压幻觉。回链：综合分册五。
