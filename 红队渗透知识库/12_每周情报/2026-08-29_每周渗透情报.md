## 3. 方法论与思路精选（专家博客 / 实验室 / 论坛回原文）

- **「未来字段」回落不能走默认 `public_send`**（GitLab / graphql-ruby）：滚动发布用指令标「此字段尚未存在」时，缺失字段若合成无 resolver 的 Field，运行时会把字段名当方法名打到 AR 对象。补丁是显式 `NilResolver`。回链：02-03、方法论十。
- **SSRF 守卫必须钉在已连接套接字上**（MLflow GHSA）：只对**原始 URL** 做 DNS/公网 IP 检查、随后跟随 302 且不钉 IP = 不完整修复。回链：Python 时效。
- **bare 临时仓 + `--cached` 三路合并 ≠ 安全沙箱**（Gitea GHSA）：bare 仓根就是 `$GIT_DIR`，补丁路径一旦落到 `hooks/` 即成执行面。回链：09-01。
- **注解缺一个枚举 = 鉴权过滤器不认领**（奇安信 CERT / Nacos）：`@Secured` 缺 `apiType` 时，Admin 与 OpenAPI 过滤器可能互相不匹配，创建用户口变成未授权。回链：Java 时效。
- **厂商写 DoS、KEV 按在野升**（NetScaler 8452）：上期 watchTowr 已警告「内存溢出上限不是 DoS」；本周 CISA 入目录，排期改 P0。回链：09-03、03-02。
- **Windows VPN 口也是边界**（IKE 33824）：测绘不要只扫 Forti/Cisco 门户；公网 UDP 500/4500 的 Windows 应答器按预认证内存面对待。回链：09-03 邻接、03-02。
- **会议软件是投递通道**（Kaspersky / Head Mare → TrueConf）：打穿会议服后改客户端安装包/页面，把马发给与会者。回链：03-01、06-02。
- **字段越界检查写成 `index == len`**（看雪 KCTF 第十题）：解释器对象字段允许 one-past-end qword，可从 arena 连续读写扩到 tcache `fd`。回链：C/C++ 时效、综合拾遗。
