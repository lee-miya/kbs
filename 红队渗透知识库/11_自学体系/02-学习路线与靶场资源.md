# 学习路线与靶场资源

## 1. 学习路线总图（L1→L3）

```text
L1 筑基（1~3 个月）
  计算机网络(TCP/HTTP/DNS) → Linux/Windows 系统管理 → Python/Go 脚本
  → Web 漏洞原理（02 分册）→ DVWA / upload-labs / pikachu 全通关
  → 单机提权（04 分册）→ Vulnhub 中级机 5 台

L2 内网（2~4 个月）
  信息收集自动化（01 分册）→ 凭据与横向（05-02/05-03）
  → 域渗透（05-01）→ vulntarget 系列 / GOAD 独立拿域控
  → HTB 中等以上域机器 10 台

L3 对抗（持续）
  C2 与免杀（06）→ 持久化反溯源（07）→ 云与容器（08）
  → 漏洞库自主补漏与补丁 diff 逆向（09）
  → HTB Pro Lab（Offshore/RastaLabs）或同级对抗环境
```

## 2. 靶场与练习平台

| 平台/靶场 | 练什么 | 备注 |
| --- | --- | --- |
| DVWA / pikachu / upload-labs | Web 基础漏洞 | L1 打地基 |
| Vulnhub | 单机打点+提权 | 从 OSCP-like 清单选机 |
| HackTheBox | 单机→域机器→ProLab | 进阶主阵地 |
| vulntarget（国产内网靶场系列） | 内网穿透、域渗透 | 贴近真实网络拓扑 |
| GOAD (Game of Active Directory) | AD 域全技法 | E5/E6 自测场 |
| WDVX / AD-lab 变种 | 域 | 备选 |
| PortSwigger Web Security Academy | Web/API 漏洞 | 免费且体系化，B 区自查配套 |
| penetration-testing practice labs（VulNyx 等） | 综合 | 轮换防手生 |
| CTF（攻防世界/HTB CTF/各类 AWDP） | 新漏洞手感、脚本能力 | 关注 Web/Misc/Pwn 与新 CVE 题 |

## 3. 认证参考（非必须，按需要）

- OSCP：单机+域全链路实战认证，L2 毕业的标志之一。
- CISP-PTE/PTS：国内认可度高的渗透认证。
- eWPTX、OSEP：Web 深入与免杀对抗方向。

## 5. 学习方法（本库的配合用法）

1. **靶场驱动**：每个分册学完后，立刻去对应靶场兑现一遍——没靶场的条目（如云）用免费额度自建实验环境。
2. **输出倒逼**：每通关一台靶机/一个实验，写 10 行复盘进 `12_每周情报` 当周的「个人沉淀」区。
3. **红蓝互换**：打完一台机，翻防守视角（日志/EDR 告警长什么样），反推自己的隐蔽方案。
4. **季度自测**：跑一遍 `01-能力自测清单.md`，把 ☐ 变成 ✅ 的过程就是你的成长曲线。

## 6. 时间预算建议（业余节奏）

| 阶段 | 每周投入 | 预期周期 |
| --- | --- | --- |
| L1 | 6~8 小时 | 2~3 个月 |
| L2 | 6~8 小时 | 3~4 个月 |
| L3 | 4~6 小时 | 长期滚动 |

原则：靶机数量不重要，「不看 walkthrough 独立完成」的比例才重要——低于 50% 说明该回炉对应分册。
