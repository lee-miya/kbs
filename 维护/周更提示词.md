# 周更 Agent 提示词模板

> 复制到每周一的 Cursor Agent / Automation 中使用。日期按当天替换。

```text
你在 KBS（攻防专业知识库）仓库中执行「每周更新」。

范围：过去 7 天（含今天）的公开安全情报与方法论。
只收录公共知识；禁止写入真实目标、IP、域名、凭证、内部组织名；
禁止写入可直接复用打穿生产的完整 exploit 载荷（写原理、条件、识别特征、建议动作即可）。

请按 `维护/每周更新SOP.md` 执行，并产出：

1. `红队渗透知识库/12_每周情报/YYYY-MM-DD_每周渗透情报.md`
   - 结构必须符合该目录 README 模板
   - 每条漏洞给「建议动作」：写入 09 漏洞库 / 观察 / 忽略

2. `代码审计知识库/增量池/YYYYMMDD/` 下至少 1 个增量 md
   - 标注类别：①新漏洞模式 ②AI挖洞 ③审计思路/CTF

3. 对有长期价值的条目回链：
   - 打点向 → `红队渗透知识库/09_漏洞库/`
   - 语言模式 → 对应审计分册「时效条目」区
   - AI/态势 → `综合分册_AI漏洞挖掘与态势.md`
   - 更新 `代码审计知识库/INDEX.md` 最近更新日期

4. 更新 `维护/内容缺口与补充路线图.md`「本周已执行」勾选
5. 若本周有余力：按路线图 P0 给一个分册加厚一小段（案例或检查单），不要大改无关文件

完成后：git status 自检无敏感信息，按仓库约定提交并推送。
```

## 人工复核清单

- [ ] 来源可信；「待核实」已标注
- [ ] 无敏感信息
- [ ] 建议动作合理（不是每条都强行入库）
- [ ] 回链条目能在分册中被检索到
