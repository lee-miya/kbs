# 周更重点关注源（滚动清单）

> 周更检索**不得只扫 KEV/NVD**。须主动覆盖本清单中的专家、博客、厂商、论坛与社区。  
> 节奏：每周至少「通扫一层 + 深挖 AI 审计案例」；源可增删，季度复审一次。  
> 红线：只摘公开信息；不入库真实目标/凭证/完整生产级 exploit。

## 使用方式

1. 周更开始时打开本文件，按 **P0 → P1 → P2** 扫过去 7 天更新。
2. 每源至少记录：有无新文、是否值得入库、一句话结论。
3. **AI 代码审计案例**（厂商战报、开源工具成果、研究员 writeup）一律进入「案例精析」流程，见 [`每周更新SOP.md`](每周更新SOP.md) 第二节 E。
4. 发现高质量新源 → 追加到本表对应档位，并在周报「方法论」区点名。

## P0 · AI 代码审计专扫（每周硬性）

> 目标：不只记「谁用了 AI」，而是拆出**可复用的提示词结构、分工、验证闭环、失败教训**。

| 类型 | 源 / 关键词 | 抽取重点 |
| --- | --- | --- |
| 厂商战报 | Oracle / Microsoft / GitHub / 国内厂商「AI 审计」「AI 挖洞」公开文 | 管线阶段、双模型/多智能体分工、验证方式、误报处理 |
| 开源项目 | DeepAudit、Codex Security、Semgrep + LLM、CodeQL+Copilot、Garak、PyRIT | Agent 角色、沙箱验证、任务 YAML/编排、适用语言 |
| 研究博客 | PortSwigger Research、Trail of Bits、NCC Group、Trailblazer 类 AI+AppSec 文 | Prompt/工具调用设计、业务逻辑洞发现路径 |
| 论文/预印本 | arXiv：LLM vulnerability discovery / multi-agent hacking；**PRWeaver**（长周期恶意 PR） | 角色划分、共享记忆、成功率与局限、跨 PR 检测 |
| 社区精选 | 看雪 / FreeBuf / 先知 / 安全客 / 洞见网安 周精选中的 AI 审计文 | 是否有可复述的「审计步骤」而非营销稿 |

## P1 · 专家与高质量博客（轮换深读）

> 每周至少精读 **2～3** 篇；优先「有代码片段 / 有 diff / 有失败路径」的文章。

### 国际（个人 / 团队博客）

| 源 | 侧重 |
| --- | --- |
| PortSwigger Research / James Kettle 等 | HTTP 走私、Web 新手法、可审计特征 |
| Project Zero Blog | 内存破坏、浏览器、利用缓解绕过 |
| Rapid7 / Tenable / Qualys Blog | Patch Tuesday 解读、利用成熟度；**TeamCity 等深度 CVE 分析** |
| The Hacker News / BleepingComputer（作索引，细节回原公告） | 线索发现，不直接当权威 |
| Corgea / 同类 AppSec 深度 CVE 分析 | fail-open、补丁回归类模式 |
| LiveOverflow / PhDays 演讲纪要 | 方法论可复述句 |

### 国内（公众号 / 实验室 / 个人）

| 源 | 侧重 |
| --- | --- |
| 长亭科技 / 知道创宇 / 奇安信攻防社区 | 边界设备、供应链、攻防演练复盘 |
| 腾讯安全应急响应中心 / 阿里云安全 | 云原生、组件洞、应急通告 |
| 看雪学院精选、安全客原创、FreeBuf 专栏 | Web/二进制/AI 交叉文 |
| 希潭实验室、各类「攻防赛事漏洞类型总结」 | 攻击面迁移、技能投资方向 |

> 名单不必穷尽：以「本周实际点开并摘录」为准；新关注的博主写进当周周报来源表。

## 检索词建议（中英混用）

**漏洞与利用**

- `CISA KEV added`、`in the wild exploit`、`Patch Tuesday`
- `未授权 RCE`、`认证绕过`、`反序列化`、`fail-open`、`补丁回归`

**AI 代码审计（必搜）**

- `AI code audit case study`、`LLM vulnerability discovery`
- `multi-agent security audit`、`CodeQL LLM triage`、`SAST + LLM`
- `AI 代码审计`、`智能挖洞`、`多智能体 漏洞`、`大模型 审计 案例`
- `Taskflow Agent`、`DeepAudit`、`AI-PTS`、`Autofix vulnerability`

**方法论**

- `source to sink`、`business logic vulnerability AI`
- `prompt for code review security`、`agent sandbox verification`
