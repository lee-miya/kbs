# 周更重点关注源（滚动清单）

> 周更检索**不得只扫 KEV/NVD**。须主动覆盖本清单中的专家、博客、厂商、论坛与社区。  
> 节奏：每周至少「通扫一层 + 深挖 AI 审计案例 + **CTF 奇技淫巧**」；源可增删，季度复审一次。  
> 红线：只摘公开信息；不入库真实目标/凭证/完整生产级 exploit。

## 使用方式

1. 周更开始时打开本文件，按 **P0 → P1 → P2** 扫过去 7 天更新。
2. 每源至少记录：有无新文、是否值得入库、一句话结论。
3. **AI 代码审计案例**（厂商战报、开源工具成果、研究员 writeup）一律进入「案例精析」流程，见 [`每周更新SOP.md`](每周更新SOP.md) 第二节 E。
4. **CTF 产出**（官方/战队 WP、赛后复盘）一律进入「奇技淫巧提炼」流程，见 SOP 第二节 F；只收**可迁移**手法，不堆题解流水账。
5. 发现高质量新源 → 追加到本表对应档位，并在周报「方法论」区点名。

## P1 · CTF 奇技淫巧专扫（每周硬性）

> 目标：从赛事 writeup 里捞**实战/审计可复用的新手法**（绕过、原语、协议扭曲、语言 quirks），不是收藏题解标题。  
> 入库标准：能写成「危险特征 / 利用条件 / 审计或打点要点」；纯脑洞、强依赖出题环境且无迁移价值的可只观察。

| 类型 | 源 / 关键词 | 抽取重点 |
| --- | --- | --- |
| 大型赛事官方 WP | DEF CON CTF / HITCON / PlaidCTF / Google CTF / 强网杯 / 护网相关公开赛 / 羊城杯 / DigCTF 等 | 新原语、新绕过链、与 CVE/组件相关的题面 |
| 战队 / 个人 WP | GitHub `*CTF*writeup*`、个人博客赛后复盘、看雪/先知「CTF WP」精选 | Web 奇技、PHP/Java/Python quirks、反序列化花样、SSRF/协议走私变体 |
| 专题聚合 | CTFtime 近期赛事 → 优质 WP；国内「XX杯官方 Writeup」PDF/仓库 | 一周内新放出的高赞/官方 WP |
| 内核 / Pwn 向 | eBPF、内核利用、浏览器/沙箱逃逸类赛题 WP | 可回链 C/C++、基础设施审计分册的验证器/原语演进 |
| Crypto / Misc 交叉 | 仅当手法可迁到真实协议、JWT、Padding、侧信道运维场景 | 避免纯数论收藏；有迁移句才入库 |

**每周最低动作**

- 检索近 7 天新放出的官方/高赞 WP（中英关键词见下文）。
- 至少精读 **1** 篇含「可迁移技巧」的 WP；抽出 1～3 条奇技 → 周报第 3/5 相关节 +（有代码层则）分册时效条目。
- 若本周无达标 WP：周报写明「无达标 CTF 技巧」及已扫赛事/关键词，不得空过不提。

## P1 · 免杀与 EDR 对抗专扫（每周硬性）

> 目标：沉淀**可复述的检测层对策**（静态/AMSI/内存/行为/流量），不是收藏免杀马下载站。  
> 入库标准：能写成「检测层 / 手法一句话 / 适用条件 / 本地自测」；完整生产载荷不入库。  
> 落点：`红队渗透知识库/06_C2与后渗透/02-免杀与载荷对抗.md` 时效条目 + 周报 3.6 节。

| 类型 | 源 / 关键词 | 抽取重点 |
| --- | --- | --- |
| 对抗实验室 | MDSec、Outflank、SpecterOps、Elastic Security Labs、Microsoft MSRC 检测文 | 新检测点、绕过被修后的残留面、行为链特征 |
| 红队公开文 | Check Point / Mandiant / Unit 42 中「loader / rootkit / sleep」类战报 | 初始访问后主机对抗手法（防御视角可反推） |
| 社区深文 | 看雪「免杀/EDR」、先知「对抗」、r/netsec、Black Hat / DEF CON 公开稿 | syscall、AMSI、PPID、LOLBins 新组合 |
| 工具动态 | donut/sRDI/pezor/Freeze/开源 C2 agent 大版本 | 是否更新 `10`；特征是否已公开老化 |

**每周最低动作**

- 检索近 7 天免杀/EDR 对抗公开文（中英关键词见下文）。
- 至少精读 **1** 篇可提炼手法；写入周报 3.6 +（达标则）06-02 时效。
- 若无达标：周报写明「无达标免杀条目」及已扫源/关键词。

## 检索词建议（中英混用）

**漏洞与利用**

- `CISA KEV added`、`in the wild exploit`、`Patch Tuesday`
- `未授权 RCE`、`认证绕过`、`反序列化`、`fail-open`、`补丁回归`

**AI 代码审计（必搜）**

- `AI code audit case study`、`LLM vulnerability discovery`
- `multi-agent security audit`、`CodeQL LLM triage`、`SAST + LLM`
- `AI 代码审计`、`智能挖洞`、`多智能体 漏洞`、`大模型 审计 案例`
- `Taskflow Agent`、`DeepAudit`、`AI-PTS`、`Autofix vulnerability`

**方法论**

- `source to sink`、`business logic vulnerability AI`
- `prompt for code review security`、`agent sandbox verification`

**CTF 奇技淫巧（必搜）**

- `CTF writeup 2026`、`official writeup`、`CTFtime writeup`
- `CTF Web trick`、`PHP type juggling CTF`、`deserialization CTF`、`SSRF bypass CTF`
- `eBPF CTF`、`kernel pwn writeup`、`browser exploit CTF`
- `官方 Writeup`、`强网杯 WP`、`护网 CTF`、`羊城杯 Writeup`、`看雪 CTF WP`
- `奇技淫巧`、`非预期解`、`出题人预期外`

**免杀 / EDR 对抗（必搜）**

- `EDR evasion`、`AMSI bypass research`、`sleep obfuscation`、`indirect syscalls`
- `PPID spoofing`、`LOLBins detection bypass`、`beacon sleep encryption`
- `免杀 loader`、`EDR 对抗`、`内存马 免杀`、`看雪 免杀`
