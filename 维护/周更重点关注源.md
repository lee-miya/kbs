# 周更重点关注源（滚动清单）

> 周更检索**不得只扫 KEV/NVD**。须主动覆盖本清单中的专家、博客、厂商、论坛与社区。  
> 节奏：每周至少「通扫一层 + 深挖 AI 审计案例 + **CTF 奇技淫巧** + **免杀/EDR** + **钓鱼/初始访问** + **边界设备** + **同类 skill 库**」；源可增删，季度复审一次。  
> 红线：只摘公开信息；不入库真实目标/凭证/完整生产级 exploit / 完整 PhaaS 套件。

## 使用方式

1. 周更开始时打开本文件，按 **P0 → P1 → P2** 扫过去 7 天更新。
2. 每源至少记录：有无新文、是否值得入库、一句话结论。
3. **AI 代码审计案例**（厂商战报、开源工具成果、研究员 writeup）一律进入「案例精析」流程，见 [`每周更新SOP.md`](每周更新SOP.md) 第二节 E。
4. **CTF 产出**（官方/战队 WP、赛后复盘）一律进入「奇技淫巧提炼」流程，见 SOP 第二节 F；只收**可迁移**手法，不堆题解流水账。
5. **免杀 / EDR** 见 SOP 第二节 G；**钓鱼 / 初始访问** 见 SOP 第二节 H；**边界设备** 见 SOP 第二节 I。
6. **同类 AI 攻防 Skill 库** 见 SOP 第二节 J；只对照缺口，禁止第三方 SKILL.md 入库。
7. 发现高质量新源 → 追加到本表对应档位，并在周报「方法论」区点名。
