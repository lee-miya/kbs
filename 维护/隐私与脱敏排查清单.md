# 隐私与脱敏排查清单

> 每次提交 / 推送前扫一遍。目标：GitHub 上只有公开技术知识，没有你的真实环境与身份细节。

## 一、禁止入库（发现即删或脱敏）

| 类型 | 处理 |
| --- | --- |
| 密码、API Key、Token、私钥 | 删除或 `[凭证已脱敏]` |
| 真实域名 / 内网外网 IP / 主机名 | 改为 `example.com` / `10.0.0.1` / `HOST-01` |
| `C:\Users\<你的用户名>\`、本机路径 | 改为 `C:\Users\<用户>\` 或删掉 |
| 邮箱、手机、微信号、真实姓名 | 删除或示例占位 |
| 客户/组织内部名称、生产实例名 | 泛化为 `[组织已脱敏]` |
| 未脱敏的「个人沉淀」、靶场/实战原始笔记 | 放到 `个人笔记/`（已 gitignore）或脱敏后再写进周报 |

## 二、允许保留

- 公开 CVE、厂商公告、通用占位（`example.com`、`corp.local`、`target.com`、`C:\Users\Public\`）
- 公开研究里已知的硬编码示例键（须在文中说明来源为公开 CVE/通告，勿混入你从真实目标抓到的键）
- GitHub 公开身份（用户名、noreply 提交邮箱）——与仓库公开属性一致，不算环境隐私

## 三、提交前命令（建议）

```powershell
git status -sb
git diff --cached
git grep -I -E "Users\\\\[^P]|@gmail\.|@qq\.|DESKTOP-|1[3-9][0-9]{9}" HEAD
```

有命中且不是文档里的虚构示例 → 先改再提交。
