## ① CodeIgniter4：内容型上传规则不校验客户端扩展（CVE-2026-63223）

- **危险特征**：校验规则仅用 `is_image` / `mime_in`；保存时使用客户端原始文件名；上传目录 Web 可达且可执行 PHP。
- **模式本质**：魔数/MIME 校验与「最终扩展名」正交缺失——`GIF89a` + `shell.php` 可通过内容检查。
- **审计要点**：
  1. 全文搜 `is_image`、`mime_in`、`UploadedFile`、`move(`、`getClientName`/`getName`。
  2. 确认是否另有 `ext_in` 或服务端重命名（随机名 + 白名单扩展）。
  3. 确认存储路径是否在 `public/` 或等价可执行目录。
- **修复对照**：≥4.7.4 对 `is_image`/`mime_in` 增加客户端扩展一致性检查；临时缓解：强制 `ext_in` + 服务端生成文件名。
- **回链**：`PHP_代码审计.md` 时效条目；红队 `09` 漏洞库。

## ① Tomcat EncryptInterceptor：解密失败仍 dispatch（CVE-2026-34486）

- **危险特征**：`EncryptInterceptor.messageReceived` 中解密在 try/catch 内，但 `super.messageReceived(msg)` 在失败路径仍执行；集群 receiver 暴露。
- **模式本质**：**安全边界 fail-open**——异常只记日志不中断；原始字节进入 Tribes 反序列化面。
- **审计要点**（可推广到任何「解密/验签 → 业务」管道）：
  1. 失败分支是否 `return` / 丢弃 / 抛出并中止。
  2. 安全补丁 diff 是否只挪动了调用顺序（回归高发）。
  3. 反序列化前是否有类型过滤。
- **版本提示**：公开资料指向需升至含修复的 9.0.117 / 10.1.54 / 11.0.21 等分支版本（以官方公告为准）。
- **回链**：`Java_代码审计.md` 时效条目；`通用审计方法论.md` fail-open 提示。

## ① Langflow：未授权发超级用户令牌 + 代码校验端点执行（CVE-2026-9198）

- **危险特征**：`/api/v1/auto_login` 对任意调用者签发 SUPERUSER；`/api/v1/validate/code` 对用户代码走 `exec` 类路径。
- **审计要点（AI/低代码平台通杀）**：
  1. 列出所有「执行用户代码 / 运行工作流脚本」端点。
  2. 默认安装是否开启 auto-login、是否绑定回环地址。
  3. 代码验证是否在定义期即执行装饰器/默认参数（导入期副作用）。
- **回链**：综合分册「AI 应用自身安全」。
