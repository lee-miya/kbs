# 增量池说明

> 审计库的「周更原料」目录，对应红队的 `12_每周情报/`。  
> **分册是权威版本**；本目录只供溯源与合并审计，日常学习请打开上级分册与 [`../INDEX.md`](../INDEX.md)。

## 规则

1. 目录名：`YYYYMMDD`（周更执行日）。
2. 文件写清：覆盖窗口、类别（①模式 ②AI ③思路）、回链目标、合并勾选。
3. 合并进分册「时效条目」后，原料**保留不删**。
4. 流程见 [`../../维护/每周更新SOP.md`](../../维护/每周更新SOP.md)。
