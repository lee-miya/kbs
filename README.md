# KBS · 攻防专业知识库

> 个人学习 / 复习 / 授权测试用的专业知识库。仅收录公开技术知识；不含任何真实目标、凭证或环境信息。
> 使用原则：仅在获得明确书面授权的目标与范围内使用；所有技术点仅用于防御研究与授权测试。

## 怎么用（学习 / 复习）

1. **定目标**：想补审计还是红队？打开对应库入口。
2. **自评**：红队用 `11_自学体系/01-能力自测清单.md`；审计用各分册文末 Checklist。
3. **精读**：按缺口跳到分册，完成文末「自测锚点」。
4. **临场速查**：红队 `09_漏洞库` / `10_工具速查`；审计 `INDEX.md` 高频速查表。
5. **跟上节奏**：每周一看 `12_每周情报` 与审计 `增量池/`，两周内把有长期价值的条目回链进分册。

## 先进性怎么保持

- **节奏**：每周一更新一次（覆盖过去 7 天）。
- **产出**：红队周报 + 审计增量原料 + 必要时回链分册。
- **纪律**：原料进增量池/周报；权威版本永远是分册；超过 12 期的旧周报归档。
- **完整流程**：见 [`维护/每周更新SOP.md`](维护/每周更新SOP.md)。
